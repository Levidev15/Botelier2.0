### Problem Statement

Pipecat supports MCP servers using stdio and SSE transports.

The SSE transport has been [deprecated](https://github.com/modelcontextprotocol/inspector/blob/c6fad3f92343ccce99ac2ad9e635a08279e09ec6/server/src/index.ts#L285) and replaced by "streamable HTTP" transport.

### Proposed Solution

Support the new streamable HTTP transport as specified here:

[https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http)

The python `mcp` package supports streamable HTTP as of [v1.8.0](https://github.com/modelcontextprotocol/python-sdk/releases/tag/v1.8.0)

### Alternative Solutions

_No response_

### Additional Context

Examples of MCP servers using the streamable HTTP transport can be found here: [https://mcpservers.org/remote-mcp-servers](https://mcpservers.org/remote-mcp-servers)

For instance [https://remote.mcpservers.org/fetch/mcp](https://remote.mcpservers.org/fetch/mcp)
