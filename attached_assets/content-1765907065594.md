| OPERA Cloud Activity API | Makes available sales activity functionality for overseeing daily tasks such as appointments, sales calls, and contact follow-up.<br>[Explore OPERA Cloud Activity API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Block API | Focuses on business block functionality, regarding a group of rooms held for guests attending an event, meeting, or function. Create blocks for an array of purposes and set aside rooms for them.<br>[Explore OPERA Cloud Block API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Back Office Operations API | Addresses end of day, which closes and balances each day’s business activities by reconciling guest folios and processing credit card transactions. End of day rolls the business date forward and prints final reports.<br>[Explore OPERA Cloud Back Office Operations API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Customer Relationship Management API | Provides access to profile management functionality. There are different types of profiles—including guest, company, and travel agent—and they store information about each.<br>[Explore OPERA Cloud Customer Relationship Management API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Sales and Event Management API | Taps into the feature designed to manage any kind of catering activity, from a simple one-hour reception to a complex affair such as a three-day business meeting with meals, breaks, and specific room setup and resource requirements.<br>[Explore OPERA Cloud Sales and Event Management API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Front Desk Master Data Management API | Grants access to master data configuration for front-office operations, including fetching past and future exchange rates.<br>[Explore OPERA Cloud Front Desk Master Data Management API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Front Desk Operations Service API | Caters to front-desk operations and statistics such as managing guest arrivals, in-house guests, and guest departures. Tackle additional tasks, including: making room assignments, creating registration cards, and sending messages to guests.<br>[Explore OPERA Cloud Front Desk Operations Service API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Housekeeping Service API | Focuses on housekeeping functionality that allows scheduling of daily room cleaning, maintenance, and housekeeping staff activities. This functionality provides information about room status, out of order/out of service rooms, and forecasting.<br>[Explore OPERA Cloud Housekeeping Service API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Integration Processor API | Addresses functionality to fetch business events generated in the property management system.<br>[Explore OPERA Cloud Integration Processor API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Inventory API | Taps into inventory functionality, including establishing sell limits for date ranges, viewing and updating property inventory, and item inventory such as rollaways and microwaves.<br>[Explore OPERA Cloud Inventory API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud List of Values Management API | Provides access to list of value (LOV) functionality. Once configured by a property, users of this API can retrieve all configured codes, including, for example, titles.<br>[Explore OPERA Cloud List of Values Management API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Price Availability Rate API | Manage room inventory by gaining a detailed view of all available and sold rooms at a property. Additional tasks that can be performed include defining conditions for stay restrictions and setting room sell limits.<br>[Explore OPERA Cloud Price Availability Rate API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Rate API | Grants access to rate availability functionality, which delivers the tools needed to define and manage rate structures. For example, users can create and manage rate codes, rate classes, rate categories, and display sets, as well as manage promotion groups and codes.<br>[Explore OPERA Cloud Rate API documentation](https://github.com/oracle/hospitality-api-docs). |
| OPERA Cloud Reservation API | Focuses on reservations related functionality such as creating and updating reservations. It deals with a range of information, including arrival date, departure date, room type, rate, and packages, and serves as gateway to the myriad functions that contribute to the guest experience.<br>[Explore OPERA Cloud Reservation API documentation](https://github.com/oracle/hospitality-api-docs). |
| Authentication API | Provides access to obtain JWT tokens based on resource owner password OAuth grant.<br>[Explore Authentication API documentation](https://github.com/oracle/hospitality-api-docs). |
